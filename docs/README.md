# VeriCargo GitHub Pages site

This folder contains the public VeriCargo homepage, privacy policy, and terms page.

## Publish with GitHub Pages

1. Commit and push the `docs` folder to the repository's default branch.
2. Open the repository on GitHub.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the default branch and the `/docs` folder, then click **Save**.
6. Wait for GitHub Pages to finish deploying.

Expected URLs:

- Homepage: `https://yucodings.github.io/vericargo_extension/`
- Privacy policy: `https://yucodings.github.io/vericargo_extension/privacy-policy.html`
- Terms: `https://yucodings.github.io/vericargo_extension/terms-of-service.html`

Enter the privacy-policy URL in the Chrome Web Store Privacy tab. For an OAuth consent screen, use the homepage, privacy-policy, and terms URLs together and keep their content consistent with the application's actual behavior.

Before publishing, confirm that `vericargo0004@gmail.com` is the correct public support and privacy contact.
